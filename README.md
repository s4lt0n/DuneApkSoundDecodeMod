# DuneApkSoundDecodeMod

Мод Dune HD Media Center для **Dune HD Homatics Box R 4K Plus, Android 14**: Dolby остаётся в bitstream, DTS/DTS-HD можно декодировать в PCM.

## Как пользоваться

**Настройки → Звук → Декодирование DTS → Настроить → «Декодировать DTS в PCM».**

- По умолчанию выключено — штатная логика Dune.
- Включено — DTS/DTS-HD исключаются из bitstream, Dolby сохраняется. В режиме PCM всё остаётся PCM.
- Выбор сохраняется; после изменения заново открой видео.

Пакет `com.dunehd.pcm` устанавливается рядом с оригиналом. Название — **DUNE DTS PCM MOD**, иконка и TV-баннер помечены **DTS → PCM / MOD**.

Текущий выпуск: **`1.0.1-13-250404_0209:1`**, `versionCode=16`. Соответствия **оригинал:ревизия**, пути и SHA-256 хранятся в [versions.json](versions.json).

## Сборка

Нужны **Python 3.10+**, **Java 8+**, **patch**; для Windows — WSL.

Положи оригинал в `apks/original/` по пути из `versions.json`; SHA-256 должен совпадать. Текущий файл: `apks/original/dune.1.0.1-13-250404_0209.apk`. APK не входят в Git.

Перед первой сборкой агент уточнит оригинал и ключ подписи: общий из репозитория, свой существующий или новый.

Из корня репозитория:

```sh
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements.txt
python scripts/setup_tools.py
python scripts/build.py
```

Инструменты скачиваются с проверкой SHA-256 из [tools.json](tools.json). Сборка применяет рецепт к оригиналу, добавляет графику и подписывает APK. Результат и отчёт — в `.build/<оригинал>/mod-<ревизия>/`.

Для конкретной версии: `python scripts/build.py --release 1.0.1-13-250404_0209:1`.

Сохранить выпуск в `apks/mod/`, записать SHA-256 и проверить:

```sh
python scripts/build.py --record
python scripts/verify.py
python scripts/versions.py
```

`--record` обновляет артефакт и реестр. Не подменяй опубликованный выпуск: сначала создай новую ревизию. Повторная сборка может иметь другой SHA-256.

## Версии и подпись

Для нового оригинала добавь запись в `originals` и проверенный рецепт в `recipes/<версия>/`. **Нативные адреса нельзя переносить на другой APK без проверки.** Для ревизии мода добавь запись в `mods`, увеличь `versionCode`, собери и проверь; затем обнови `current`. Сохраняй опубликованные соответствия и прежнюю подпись для совместимых обновлений.

В `signing/` намеренно опубликованы общий ключ разработки и пароль. Сертификат действует до **23 марта 2054 года**; параметры — в `versions.json`. Любой может подписать совместимое обновление: этот ключ не подтверждает автора APK.

Собственные ключи и пароли храни в игнорируемом `signing/local/`. Локально настрой поля `signing` в `versions.json`: пути, alias, отпечаток сертификата и `publicDevelopmentKey=false`. Эти изменения не включай в коммит; общий ключ сохраняй. Смена сертификата не позволит обновить установленную копию с прежней подписью.

## Что внутри и что проверено

Smali-фильтр `DtsPcmSettings.filterMask()` применяет `mask & ~0x0180` и выключает `dts-core-only`. Checkbox сохраняется через FSFile; `/config/decode_dts_pcm` — виртуальный путь Dune. ARM-вставка в `libduneshell.so` добавляет пункт меню и вызывает Android-диалог. Рецепты — в `recipes/`, графика — в `assets/`.

[Отчёт](docs/verification.json) содержит статические проверки, подпись и контрольные суммы. Дополнительные проверки ARM-вставки и DEX-политики:

```sh
python -m pip install -r requirements-dev.txt
python scripts/assemble_native.py
python tests/check_native.py
python tests/check_policy.py
```

Для пересборки ARM-вставки нужен Clang с ARM target; обычная сборка использует готовый проверенный образ.

**На приставке APK не устанавливался: Android UI, смена дорожек, реальный PCM/bitstream и полное декодирование DTS:X не проверены.** Для HTTP/ExoPlayer запрет bitstream не добавляет отсутствующий системный DTS-декодер. При проверке закрой другую копию Dune и проверь Dolby ↔ DTS, каналы и синхронизацию; штатное обновление может предложить оригинальный APK производителя.
